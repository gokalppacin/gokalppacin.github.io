Pilot Rest Time Support

Pilot Rest Time is an offline planning tool that helps pilots create in-flight crew rest schedules using manually entered flight times and settings.

Need Help?

For questions, suggestions, or technical issues, please open a support request through GitHub Issues.

Open a Support Request

Helpful Information

When reporting an issue, please include your iPhone model, iOS version, and a brief description of what happened.

Pilot Rest Time does not require an account and does not use external services.
